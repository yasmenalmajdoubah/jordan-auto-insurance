# Jordan Auto Insurance

نظام تأمين مركبات — Angular + ASP.NET Core

## المرحلة 0 (الحالية)
- تأسيس Backend + Frontend
- JWT Login + Roles
- Audit Log في الـ API
- قاعدة بيانات محلية SQLite

## تشغيل Backend
```bash
cd backend
dotnet run --launch-profile http
```
API: http://localhost:5213  
Swagger: http://localhost:5213/swagger

حساب تجريبي:
- المستخدم: `admin`
- كلمة المرور: `Admin@123`

## تشغيل Frontend
```bash
cd frontend
npm start
```
App: http://localhost:4200
